# melafifiapps.github.io

A simple static website managed with Xcode and published automatically via **GitHub Pages**.

## 🖥 Live Site
👉 [https://mohamedelafifi-source.github.io/melafifiapps.github.io/](https://mohamedelafifi-source.github.io/melafifiapps.github.io/)

## 🧰 Project Notes
- Edited locally in **Xcode** for convenience (HTML / CSS / JS only).
- No compilation or build target required — Xcode is used only for editing and Git.
- Pushing to the `main` branch automatically redeploys to GitHub Pages.

## 📁 Repository Layout

ndex.html
styles.css
script.js
.nojekyll
.gitignore
README.md

## 🚀 Updating the Site
1. Open the project in Xcode.  
2. Edit any HTML, CSS, or JS file.  
3. **Source Control ▸ Commit** → add a message (e.g., “update home page”) → **Commit & Push**.  
4. Wait 1–2 minutes, then refresh the live site link above.
